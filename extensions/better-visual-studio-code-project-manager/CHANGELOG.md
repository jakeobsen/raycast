# Project Manager Changelog

## [Initial Version]

- Search projects from a VSCode Project Manager-style `projects.json`.
- Actions: Open in VSCode (incl. `vscode-remote://`), Open in Terminal, Open in lazygit (inside Terminal.app), Open Git Remote in Browser, Show in Finder, Open With, Copy Name, Copy Path, Reset Ranking, Move to Trash.
- Tag grouping + tag filter dropdown, frecency sorting, fuzzy search.
