# Hello World

Minimal Raycast extension demonstrating the monorepo Makefile workflow. Invoking the **Say Hello** command shows a HUD reading "Hello from Raycast monorepo!".

Seed/example for the repo — deletable once you have real extensions.

## Develop

From the repo root:

```bash
make deps-hello-world     # install dependencies
make dev-hello-world      # register with Raycast + live reload
```

Open Raycast and run **Say Hello**. Press Ctrl+C in the terminal to stop the dev server.

## Build

```bash
make build-hello-world
```
